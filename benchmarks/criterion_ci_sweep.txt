Why this file exists
--------------------
The sweep is quoted as the CI-equivalent bench command, but it had never been
recorded because it could not run to completion. Three independent blockers, all
now fixed in this repo, each aborted it:

  1. `cargo bench` selected the libtest harness for the lib and the bins before
     any criterion target, and libtest rejects criterion's flags:
     "error: Unrecognized option: 'output-format'". Fixed by `bench = false` on
     `[lib]` and the three `[[bin]]` targets (there are no `#[bench]` fns there).
  2. `benches/mindcraft_fmt.rs` called `.expect("format failed")` on a corpus
     that needs `std-surface` to parse; the panic aborted the whole sweep at
     exit 101, leaving every later target unmeasured.
  3. `benches/operations.rs` and `benches/shapes.rs` did the same on fixtures the
     type checker refuses in this feature set — and two fixtures triggered the
     compiler's fail-closed *panic* refusal for `ArrayLit` in value position,
     which a `Result` match cannot observe.

(2) and (3) are fixed by `benches/common/mod.rs::accepts`, which probes a fixture
once, prints what it could not measure and why, and skips only that fixture. No
measurement is altered: an accepted fixture is timed exactly as before.

How to read the skips
---------------------
  * "mindc not built ... skipping" — the kernel benches need a compiled `mindc`
    to build their `.so`; they self-skip by design in a plain `cargo bench`.
  * "not usable in this feature build" — the fixture needs a feature this build
    does not have. Run the sweep with the fuller feature set to measure it.
Neither is a failure, and neither is silent: every unmeasured input is named.
