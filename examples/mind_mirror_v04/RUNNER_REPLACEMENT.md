# `mirror_gate.py` — replacement checklist

`mirror_gate.py` is a **test runner**, not a compiler stage. It compiles no
MIND semantics: it drives the frozen pure-MIND compiler, runs the resulting
native mirror over a fixed vector corpus, and judges the exits and bytes. It is
nevertheless first-party Python in the build/test path, so it is tracked here
as **migration debt** with an explicit replacement target: a MIND runner.

Nothing in this file may be dropped during that migration. Each property below
is load-bearing and was paid for by a real defect or a review finding.

## Properties the replacement must preserve

1. **Toolchain identity is enforced, not printed.** The compiler ELF digest and
   the composed std seed-blob digest are compared against pinned constants; a
   mismatch fails the run. Printing them attests to nothing, because identical
   output would appear after either changed underneath the gate.
2. **Source image composition matches the production bridge exactly** —
   `[8B user_lo LE][8B src_len LE][std_blob ++ user_src]` on stdin, ELF on
   stdout, with the seed module count checked against the frozen count.
3. **Expected exit per vector comes from the manifest**, which is generated by
   the reference oracle, never from the program under test.
4. **The consumed prefix length is oracle-derived.** Positives are byte-compared
   over exactly that length. Comparing against `input[:len(emitted)]` is
   self-lengthed and admits a short-but-correct prefix.
5. **The dump run's exit must equal the vector's expected exit**, not merely
   zero: a remainder-refused vector exits 20 after emitting a complete prefix.
6. **A remainder-refused vector must actually have a remainder.**
7. **Both positives and negatives must be present**, or the run is vacuous and
   is refused as such rather than reported as a pass.
8. **Recipe vectors are rebuilt in scratch and pinned by size and digest**, so
   an oversized fixture needs no permanent binary in the repository.
9. **Every subprocess is bounded**; a hang surfaces as a distinct exit code.
10. **All scratch is released on every exit path**, including failure branches
    and the pinned-digest refusal.
11. **The mutation switch stays.** A gate whose reddening mutation cannot be
    stated is decoration; the recorded mutations are part of the evidence.

## What blocks replacement today

A MIND runner needs, beyond the current frozen native surface: process spawn
with piped stdin/stdout and an exit code, directory enumeration, SHA-256, and
TSV text parsing. The mirror itself already demonstrates file read, argv, raw
memory and byte comparison in pure MIND.

## Checklist

- [ ] MIND SHA-256 over a byte range, verified against the pinned digests here
- [ ] MIND process spawn with piped stdin/stdout and exit-code capture
- [ ] MIND directory enumeration for the vector corpus
- [ ] MIND TSV parse of `MANIFEST.tsv`
- [ ] Port properties 1-11 above, each with its reddening mutation restated
- [ ] Run both runners over the same corpus and require identical verdicts
- [ ] Retire `mirror_gate.py` only after that agreement is demonstrated
